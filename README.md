# Arooba Hussain | Personal Portfolio

Welcome to my personal portfolio website! I am Arooba Hussain, an M.Phil. Education scholar at Government College Women University Faisalabad (GCWUF). This portfolio showcases my skills, projects, educational background, and experience.

## About the Project

This is my personal portfolio website, developed as part of my Web Development and Data Analytics learning journey. The website presents my academic background, technical skills, projects, and contact information in a responsive and interactive design.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Dark and light mode
* Interactive navigation menu
* About me section
* Skills and technologies section
* Projects with category filters
* Project details modal
* Contact section
* Smooth and user-friendly interface

## Technologies Used

* HTML5 – Website structure
* CSS3 – Styling and responsive layout
* JavaScript – Interactive functionality
* GitHub – Version control and hosting
* GitHub Pages – Website deployment
